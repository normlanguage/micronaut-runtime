# Micronaut Runtime

[English](README.md) | [简体中文](README.zh-CN.md)

The adapter declaration and runnable example are in `micronaut/runtime`. It pins Micronaut Context 5.1.13 and defines its package coordinates in [module.norm](micronaut/runtime/module.norm). The public API covers the standard startup entry point and embedded-server lifecycle.
